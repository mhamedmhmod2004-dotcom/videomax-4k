# لقطة — موقع عربي لتنزيل الفيديوهات بجودة عالية

موقع كامل (واجهة عربية + خادم حقيقي) لمعاينة الفيديوهات العامة وتنزيل الملفات التي تملك حق الاحتفاظ بها. يدعم جودة المصدر المتاحة، بما فيها 1080p / 2K / 4K عند وجودها، ودمج الصوت والصورة بواسطة FFmpeg، واستخراج MP3.

**مهم:** لا يوجد برنامج يضمن تنزيل الفيديو من *جميع* المنصات. يعتمد هذا المشروع على yt-dlp وقد تتغير قدراته مع سياسات المنصات. لا يدعم تجاوز DRM أو الفيديوهات الخاصة التي تحتاج إلى صلاحيات. لا تستخدمه لتنزيل مواد دون إذن أو بما يخالف القوانين وشروط الخدمات المعنية.

## الطريقة الأسهل: Docker

1. ثبّت Docker Desktop أو Docker Engine مع Docker Compose.
2. افتح Terminal / PowerShell داخل مجلد المشروع (حيث يوجد `docker-compose.yml`).
3. شغّل:

   ```bash
   docker compose up --build
   ```

4. افتح **http://127.0.0.1:8000** في المتصفح. أوقف الموقع بـ Ctrl+C.

> إعداد Docker يتضمن Python وFFmpeg وDeno، لتوفير دعم أفضل ليوتيوب. ربط المنفذ محليّ فقط بطبيعته لأسباب أمنية.

## تشغيله مباشرة على Windows

1. ثبّت **Python 3.11 أو أحدث**، واضبط خيار `Add Python to PATH`.
2. ثبّت **FFmpeg** وأضف مسار ملفاته التنفيذية إلى `PATH` (ضروري لدمج صوت وفيديو 1080p+).
3. ثبّت **Deno 2.3+** مع إضافته إلى `PATH` (ضروري لدعم YouTube الكامل مع yt-dlp الحديث).
4. انقر مرتين على `start_windows.bat`، وبعد تثبيت الحزم سيفتح `http://127.0.0.1:8000`.

يمكن بدلًا من ذلك تشغيل:

```bash
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

على Linux/macOS يمكنك استخدام `./start_linux.sh` بعد تثبيت Python وFFmpeg وDeno.

## كيف يعمل؟

- تدخل رابطًا من YouTube / Instagram / TikTok / Facebook / X / Vimeo / Reddit / Pinterest وغيرها من النطاقات المعتمدة.
- يقرأ الخادم معلومات الفيديو والجودات المنشورة *فعلًا* من المصدر.
- تختار جودة الفيديو `MP4` أو الصوت فقط `MP3`.
- تبدأ عملية خلفية محدودة التوازي؛ تعرض الصفحة مستوى التقدم، وعند اكتمالها توفر رابط تنزيل الملف.
- تظهر الجودات المتاحة فقط؛ لا يتم رفع الدقة اصطناعيًا.

## إعدادات الخادم

متغيرات بيئة اختيارية:

- `DOWNLOAD_DIR` مكان تخزين التنزيلات المؤقتة.
- `MAX_FILE_SIZE_MB` الحد الأعلى لحجم ملف الناتج؛ الافتراضي 1024 ميجابايت.
- `MAX_DURATION_MINUTES` أقصى مدة للفيديو؛ الافتراضي 120 دقيقة.

الملفات تُحذف تلقائيًا بعد انتهاء صلاحيتها (ساعتان) **عند وصول طلب جديد**. توقف/إعادة تشغيل الخادم يفقد حالة عمليات التنزيل. لا توجد قاعدة بيانات أو حسابات مستخدمين في هذه النسخة.

## عند نشره للعامة

هذه نسخة جاهزة **للتشغيل المحلي** وليست خدمة عامة محصنة ضد سوء الاستخدام. قبل النشر أضف تسجيل دخول/مفتاح وصول، حدود استخدام حسب IP، تنظيفًا دوريًا للملفات، رقابة على الاستهلاك، عزلًا للشبكة الصادرة، وسياسة خصوصية وحقوق نشر. يجب توفير خادم له سعة تخزين وبيانات كافية؛ الاستضافات الثابتة فقط (مثل GitHub Pages) لا يمكنها تشغيل التحميل الفعلي.

## حل مشكلات شائعة

- **فشل تحليل رابط:** قد يكون الفيديو خاصًا أو المصدر غيّر طريقة الوصول. حدّث yt-dlp: `python -m pip install -U "yt-dlp[default]"` ثم أعد التشغيل (أو أعد بناء Docker).
- **يوتيوب لا يعرض الجودة كاملة:** تأكد من تثبيت Deno 2.3+ (ضمن Docker تلقائيًا)، وأن yt-dlp وyt-dlp-ejs محدثان.
- **صوت غير موجود / فشل دمج:** تأكد من وجود `ffmpeg` و`ffprobe` في PATH.
- **فتح ملف HTML وحده:** لا يكفي. افتح الموقع بعد تشغيل الخادم على المنفذ 8000.
- **روابط لا تعمل:** لا يعد الدعم مضمونًا لمحتوى خاص أو مدفوع أو محمي DRM أو بعض المنصات.
